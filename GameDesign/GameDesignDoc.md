# GameDesignDoc



# 什么是核心玩法CoreGameplay?

是玩家会一直做的交互


# 什么是好玩的核心玩法

1. 玩家必须理解他们的目标
2. 玩家必须面对一个挑战
3. 交互/控制必须简单且直观
4. 屏幕必须展示足够的游戏环境（让玩家感到舒适）
5. 核心玩法必须满足感官体验（是否爽juiciness）


### 工具选择越多，体验越好

需要给玩家一个短期挑战，以及完成挑战的障碍，并且给予玩家克服障碍的工具

设计使用多个基础组件让玩家完成多个挑战
